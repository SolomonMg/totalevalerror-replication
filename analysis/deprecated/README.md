# Deprecated Scripts

Scripts in this folder are superseded by newer versions in the parent `analysis/` directory. They are kept for reference only — **do not run them** for the replication pipeline.

## Contents

| File | Superseded by | Reason |
|---|---|---|
| `04g_sim_underestimation.R` | `../04g2_sim_underestimation_balanced.R` | `04g` used an imbalanced DGP where `σ²_ρ = 0.04` dominated, producing one large coverage jump between scenarios B and C. `04g2` rebalances `σ²_ρ`, `pop_var(τ)`, and `pop_var(λ)` to similar magnitudes (~0.015 each) so each added random effect produces a comparable staircase step. The paper's SI §D.7 describes the `04g2` design. Figure `fig_underestimation_pnas_v2.pdf` is generated by `04g2`. |
| `06_sim_recovery.R` | `../06_sim_scoring_recovery.R` | Early scoring-method simulation (N_SIM=100, 287 lines). Superseded by `06_sim_scoring_recovery.R` (v5, N_SIM=200, 1283 lines, item-level tournament design with 768 conditions across 5 Likert pathologies). The paper's SI §D.6 describes the v5 design. |
| `scenario_c_variance_capture.tex` / `.pdf` | (none) | Standalone note explaining why Scenario C in the deprecated `04g_sim_underestimation.R` captured `σ²_αρ` but not `σ²_ρ`. Obsolete since `04g2` uses a different scenario structure. Retained for historical context. |

## Outputs

Deprecated outputs are archived alongside their producing scripts:

- `data/processed/deprecated/sim_underestimation{,_summary,_20researchers}.csv` — produced by `04g_sim_underestimation.R`
- `figures/deprecated/sim_recovery.{pdf,png}` — produced by `06_sim_recovery.R`

The authoritative Figure 2 outputs for the PNAS submission use the `_v2` suffix (e.g., `figures/fig_underestimation_pnas_v2.pdf`, `data/processed/sim_underestimation_summary_v2.csv`) and are generated by `../04g2_sim_underestimation_balanced.R`.
